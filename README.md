# Flower_Recognition
Flower Recognition using Machine Learning classifiers, PCA, feature selection, cross-validation, stacking, and AdaBoost.


This project focuses on flower image classification using extracted image features and multiple machine learning classifiers.

## Methods
- Data normalization
- PCA dimensionality reduction
- Feature selection
- 4-fold cross-validation
- GridSearch
- Classical ML classifiers
- Stacking ensemble
- AdaBoost ensemble

## Evaluation Metrics
- Accuracy
- ROC-AUC
- F1-score

## Dataset
Flowers Recognition dataset from Kaggle.

## Tech Stack
- Python
- Scikit-learn
- Pandas
- NumPy
- Matplotlib
